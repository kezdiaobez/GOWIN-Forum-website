# GOWIN-Forum-website
Website for GOWIN customers questions and concerns.
website link: forum.gowinsemi.com.
This website runs on apache 2 web server and uses mssql server. The forum tab lets users access discussions on gowin products. This website's code is open-source. User account registration requires approval from admin. Sql server connection scripts are not included.
